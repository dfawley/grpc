# Appendix D. gRFC Traceability Matrix

<!-- Sources: grpc-proposal/A*.md and G*.md (titles, Updated-by headers), the "Sources" comments at the top of every spec file -->

This appendix maps each gRPC design proposal (gRFC) in the `grpc/proposal`
repository to the sections of this specification that describe its current
effect. gRFCs are written as changes to the behavior of their time, so a
later gRFC often amends or replaces part of an earlier one. This
specification describes only the result (see
[Introduction and Conventions](../00-introduction/README.md), 0.10).
Mechanisms that were removed are summarized in
[Appendix E](e-historical.md).

This appendix is informative.

## D.1 Status Values

| Status | Meaning |
| --- | --- |
| **Incorporated** | The gRFC's behavior is specified in the listed sections. Any amendments by later gRFCs are listed in the notes and are reflected in the specification. |
| **Partially incorporated** | A significant part of the gRFC is specified. Other parts were replaced by a later gRFC, or fall under an exclusion. The notes say which. |
| **Superseded** | None of the gRFC's normative content is current. It was replaced by the gRFC(s) named in the notes. |
| **Excluded** | Deliberately not described: the gRFC is still in review, depends on unmerged work, or covers a feature outside the scope of this specification (see [Scope](../00-introduction/README.md)). |

> [!NOTE]
> gRFC numbers with no file in the repository (for example A4, A7, A11–A13,
> A19, A20, A22, A23, A25, A34, A35, A49, A67, A70, A73, A77, A84, A92, A93,
> A98–A100, A104, A106, A109, A111, A112, A116, A117, A119) were never merged,
> or were withdrawn, and do not appear below. Unmerged features referenced by
> merged gRFCs (RLQS, ext_authz, ext_proc, and the unified matcher and CEL)
> are not described in this specification. Cluster specifier plugins and RLS
> have no gRFC; they are specified from the protos and implementations in
> [RouteConfiguration](../09-xds/03-resources/03-route-configuration.md)
> ([Cluster Specifier Plugins](../09-xds/03-resources/03-route-configuration.md#52-cluster-specifier-plugins))
> and [`rls`](../04-client-channel/lb-policies/rls.md).
